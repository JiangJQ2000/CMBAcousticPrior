CMB acoustic prior for Cobaya

A Gaussian prior on (θ*, ωb, ωbc) from the CMB that does not assume a late-time cosmology. Combine it with BAO, supernovae or any other late-time data. Pick a dataset and a Boltzmann code, then copy the config and run it.


  
Save as , then: pip install cobaya camb and cobaya-run 

  
For CLASS, keep reio_parametrization: reio_none; the prior's θ* excludes reionization. Keep every sampled CLASS parameter in input_params.
